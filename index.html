Signal summary

Fairness policy

Emergency priority: emergency vehicles sit in a binary max-heap (priority 5→1, then earliest arrival, then lowest ID). When one is waiting on a red approach, the controller ends the current green early and gives that approach the next green.

Fairness: emergency preemption is capped at 2 consecutive phases. After that the signal rotates to whichever approach has waiting vehicles, so normal FIFO traffic cannot starve.

Metric definitions

All numbers come from the C backend. Time is simulated: 1 tick = 1 simulated second at 1x. Average waiting time = total ticks between a vehicle being added and crossing ÷ vehicles processed. Throughput = processed vehicles per 60 simulated ticks. Max queue = largest single-direction queue seen. Active intersections = road-network intersections while the simulation is running.

About

A college DSA project. The backend is written in C: linked-list FIFO queues (normal vehicles), a binary max-heap (emergency vehicles), an adjacency-list graph, BFS and Dijkstra with a binary min-heap. This page only displays what the REST API returns - no algorithm runs in JavaScript.
